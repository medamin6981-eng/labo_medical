# Gestion d'un laboratoire d'analyses médicales

Application web de gestion d'un laboratoire d'analyses médicales (Spring Boot, Angular, PostgreSQL)[cite: 1, 2].

## Structure du dépôt
- `docs/` : diagrammes, dictionnaire de données, maquettes, rapport[cite: 5]
- `database/` : scripts SQL et jeu de données de démonstration[cite: 5]
- `backend/` : API REST Spring Boot (Java)[cite: 4, 5]
- `frontend/` : application web Angular[cite: 4, 5]
